SETUP / VERSION {{ companion_version }}

Bring your music home.

  1. Download and extract the ZIP into a folder you control.
  2. Read the included README.txt. You need Windows and an existing 64-bit CPython 3.12 installation; this release does not install Python.
  3. Double-click START_COMPANION.cmd, then open http://127.0.0.1:8947/. Keep the terminal open while you listen; Ctrl+C stops the companion.
  4. Run CONFIGURE_COMPANION.cmd to supply your existing checksum-valid catalog, package cache, and optional read-only Songs folder. The first launch shows an unavailable catalog until you supply one. Nothing is discovered or downloaded automatically.

What you are downloading

A portable Python tool with its runtime dependencies included. It runs locally in your browser. This is an unsigned ZIP, not a native Windows application or a signed installer. It creates no new account and includes no catalog, cached audio, songs, or personal library inventory.

Preview availability

Audio is available only for supported packages already in your cache. Stem-mix previews are capped at 45 seconds. A chart in the catalog does not guarantee a playable preview or a downloadable song. Unavailable audio is shown clearly in the player.

Your library stays in your hands

The companion's library inventory is read-only. This release can copy a chosen cached .sng package into a separate local sandbox after an explicit action. It does not install into your real song library or extract song folders. This public page cannot read your folders or run local installation operations.
